# @AnonThread

**Anonymous signals from the underground**

A minimalist, ephemeral imageboard where users can post and reply completely anonymously. No accounts, no history, no traces—everything fades eventually.

## 🌟 Features

- **Complete Anonymity**: Post without creating an account or logging in
- **Ephemeral Content**: Messages don't persist forever—embrace the temporary nature of the platform
- **TOR-Style Routing**: Privacy-focused infrastructure for secure, anonymous communication
- **Threading System**: Reply to posts with `>>1` style references, classic imageboard format
- **Live User Counter**: See how many others are online in real-time
- **Clean Minimalist UI**: Dark theme, distraction-free interface focused on the conversation

## 🎯 Philosophy

AnonThread embraces the philosophy that not everything needs to be permanent. It's a space for raw, unfiltered thoughts and discussions without the baggage of digital identity, post history, or algorithmic curation.

> "No accounts. No history. Everything fades eventually."

The platform is designed for genuine, spontaneous discourse—where ideas matter more than reputation, and conversations exist in the moment.

## 🚀 Tech Stack

- **Frontend**: HTML, Css, Js 
- **Backend**: Supabase
- **Hosting**: Netlify
- **Styling**: Custom CSS with dark theme
